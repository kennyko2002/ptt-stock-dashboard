# PTT Stock 情緒儀表板

PTT Stock 版盤後閒聊推文情緒分析儀表板（靜態版）。

## 內容

- `index.html` — 儀表板頁面（ECharts 繪圖，無後端依賴）
- `data.json` — 每日更新的資料（今日綜合指標 + 各情緒指標 + 歷史時間序列 + TAIEX）

## 資料來源

- **PTT 推文**：PTT Stock 版每日盤後閒聊（公開資料），經 Qwen3.6-35B 大語言模型做 11 維情緒分類
- **情緒指標**：fomo（害怕錯過）、fear（恐慌）、greed（貪婪）、despair（絕望）、bullish（看多）、bearish（看空）、sarcasm（反串）加權平均 + 綜合指數（Emotion Index, 0-100）
- **大盤**：台灣加權指數（TAIEX）收盤價（待 TWSE 資料源恢復後自動帶入）

## 更新頻率

每個交易日早上 8:00 自動執行（本機排程）：爬取前一日盤後閒聊 → 情緒分類 → 聚合 → 更新 `data.json` → 推送本 repo。

## 互動功能

- 今日各指標儀表（含指針、紅黃綠區間語意）
- 歷史指標 × TAIEX 雙軸圖（下拉切換 8 種指標）
- 配色語意：綠=樂觀/正向、紅=恐慌/負向、黃=中性區、藍=中性指標（僅顯示強度）
